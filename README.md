# Licence Radio Amateur - Cours F6GPX

Cours de préparation au certificat d'opérateur du service amateur, basé sur le cours de **F6GPX (Jean-Luc Fortin)** du Radio-Club de la Haute Île (F6KGL/F5KFF).

## Consulter le cours

Le cours est disponible en ligne : **[Accéder au cours](https://scttpr.github.io/licence-radio/)**

## Contenu

### Réglementation
- R-1 : Classes d'émission et conditions techniques
- R-2 : Fréquences et puissances autorisées
- R-3 : Alphabet international et code Q
- R-4 : Conditions d'exploitation et indicatifs
- R-5 : Connaissances techniques de base

### Technique
- Chapitres 0-4 : Bases d'électricité (Ohm, Joule, circuits LC...)
- Chapitres 5-6 : Composants actifs (diodes, transistors)
- Chapitres 7-12 : Radioélectricité (amplificateurs, antennes, modulations...)

### Annexes
- Récapitulatif des formules
- Adresses utiles et centres d'examen
