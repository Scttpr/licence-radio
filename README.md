# Licence Radio Amateur - Cours F6GPX

Cours de préparation au certificat d'opérateur du service amateur, basé sur le cours de **F6GPX (Jean-Luc Fortin)** du Radio-Club de la Haute Île (F6KGL/F5KFF).

## Contenu du cours

### Réglementation
- Classes d'émission et conditions techniques
- Fréquences et puissances autorisées
- Alphabet international et code Q
- Conditions d'exploitation et indicatifs
- Connaissances techniques de base

### Technique
- Bases d'électricité (Ohm, Joule, circuits LC...)
- Composants actifs (diodes, transistors)
- Radioélectricité (amplificateurs, antennes, modulations...)

### Annexes
- Récapitulatif des formules
